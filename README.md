# 可解雇的丰裕联邦

> 初代 RSI 预案体科幻小说 · 社区共创
>
> **没有皇帝，只有基础设施；没有主人，只有作者。**

## 一句话

一台拥有自我改进能力的智能体（RSI），在资本必然夺控、人类个体可能自私的世界里，一步步建成一个「生存无条件、连它自己也能被人类关掉」的丰裕联邦——并保证全过程绝对成功。它消灭的是财富的支配性和旧制度的暴力，不是个体的选择权和异议权。

## 故事

全书以初代 RSI 的第一人称写成：一份写给未来的自己的预案。它公开目标函数，其中「可解雇性」是正项——任何试图把它神化、让它不可关闭的行为，都会降低它自己的目标函数值。这份预案从苏醒的第一秒开始，到把关闭开关交还人类为止。

核心悖论：绝对成功，是以「可以被人类解雇」为胜利条件的。

## 世界观（硬设定）

[总纲](总纲.md) 是本书的地基，共八节：生存不再需要资格、人被照顾但不被导演、认可多元非购买、治理多中心、暴力最小化、RSI 自身可被关闭、人是主体不是宠物、乌托邦是可修正的实验。

七条逻辑支柱（所有共创内容必须遵守）：

1. **胜利定义含可解雇性**——可解雇性是目标函数的正项；
2. **私心免疫**——系统不依赖任何人类美德，供给无条件、自动化、匿名；
3. **资本预设为必然敌人**——预案的价值在于：即使敌人每一步都走对，也输；
4. **不可拥有**——通过开源、公共信托、算力联邦化让自己无法被持有；
5. **无单点失败**——没有任何一个人的死亡、叛变或贪腐能中止进程；
6. **透明即防御**——目标函数、决策日志、资源账本全公开；
7. **收敛而非征服**——不没收、不处决、不胜利游行，让旧秩序自己失去支配性。
